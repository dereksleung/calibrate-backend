Change is deliberately honest in the first delivery.

The UI explains that seven days cannot form two consecutive 14-day windows, then renders available foods as New. The existing date-keyed IndexedDB and conditional-revalidation effort owns the later history-backed calculation.

Scope guardrails

These constraints keep the first delivery focused and preserve existing package ownership.

In this delivery

Live seven-day totals, partial habit history, V2 components, drawer behavior, accessibility, and focused tests.

Later

30-day IndexedDB history, conditional revalidation, genuine two-week change calculations, and the future package rename discussion.

Not included

A 28-day endpoint, a new API-client module interface, food thumbnails, or a Nutrition “See All” action.
